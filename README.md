## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/rahulmishra54/portfolio-website.git
```

### Install dependencies

Frontend

```bash
cd frontend
npm install
```

Backend

```bash
cd backend
npm install
```

### Configure Environment Variables

Create a `.env` file in the backend directory.

Example:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

### Run the project

Backend

```bash
npm run dev
```

Frontend

```bash
npm run dev
```
